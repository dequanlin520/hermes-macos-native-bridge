# Hermes macOS Native Bridge 0.1.0-rc.1

This RC1 artifact is unsigned and not notarized. It is intended only for controlled internal validation by maintainers, clean-user-account testers, and second-Mac external validation operators.

Public distribution is blocked until Developer ID Application signing and Apple notarization pass. Do not describe this artifact as safe for general public installation.

## Supported

- Native menu-bar application
- XPC 1.8 Bridge service
- Hermes executable/version discovery
- Isolated Hermes Agent lifecycle
- Dynamic endpoint ownership
- `/api/status` readiness
- Reconnect and controlled restart
- Diagnostics
- Permissions status
- Audit/security status
- Emergency stop
- User-scoped install/uninstall

## Unsupported

- Hermes request submission
- Request status/cancel
- Approval response
- Private `/api/ws`
- Arbitrary prompts
- Tool execution
- Arbitrary shell
- GUI computer use
- Browser automation
- Arbitrary AppleScript/JXA
- Broad process control

Request submission, request status, request cancellation, and approval response are unsupported with `transport.route-unsupported`.

## Compatibility

- Product version: `0.1.0-rc.1`
- Target tag: `v0.1.0-rc.1`
- Package type: `app-distribution-bundle` ZIP
- XPC protocol: `1.8`
- Tested Hermes Agent: `0.18.2`
- Installation scope: current macOS user

## Distribution Warning

The current artifact is unsigned, not notarized, and limited to controlled internal validation. Public release remains blocked until Developer ID Application signing and Apple notarization are available and verified.

This RC does not claim external users, production readiness, or official Hermes support.
